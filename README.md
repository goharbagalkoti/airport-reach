# Airport Reach ✈️

## Overview
Airport Reach is a geospatial web application that identifies the nearest airport for different cities and calculates the great-circle distance between them.

## Features
- Explore cities and airports on an interactive map.
- Find the nearest airport for each city.
- Calculate distances in kilometres.
- View geographic data through an easy-to-use interface.

## Technologies Used
- Python
- Pandas
- NumPy
- JavaScript
- HTML and CSS
- AWS (planned/integration, depending on deployment status)

## Dataset
The project uses city and airport geographic datasets, including latitude and longitude coordinates.

## Project Structure
- `pipeline/` – Dataset processing
- `web/` – Web application and map interface
- `web/data/` – Generated geographic data

## Run Locally
1. Clone the repository.
2. Install the required Python packages.
3. Generate the sample dataset.
4. Run the web application.

## Purpose
To make airport accessibility easier to understand through geographic distance calculations and interactive visualization.
